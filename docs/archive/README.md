# Archive

Specifications and reviews of implemented, merged capability slices, kept as history: why a decision was made, what was verified, and against which source commits. Later slices may have changed the code they describe. For current behavior read [architecture](../architecture.md), the [ADRs](../adr), [coding style](../coding-style.md) and [CONTEXT.md](../../CONTEXT.md); the [ledger history](migration-ledger-history.md) records the order the slices were built in.

- [specs/](specs) behavior specifications, named by capability slice.
- [reviews/](reviews) the review and verification record of each slice, plus the 2026-10-07 business-flow audits.
- [research/](research) design research that fed a slice.
- [rebuild-plan.md](rebuild-plan.md) the original staged plan (2026-10-04); its lasting rules are in architecture's outgoing durability rules and ADR 0002.
- [foundation-review.md](foundation-review.md) the review of the initial repository foundation.
- [migration-ledger-history.md](migration-ledger-history.md) every earlier resume checkpoint, slice record and the original capability backlog.

Active and unbuilt specifications live in [docs/specs](../specs).
