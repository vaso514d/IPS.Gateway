# Archive

Specifications and reviews of implemented, merged capability slices, kept as history: why a decision was made, what was verified, and against which source commits. Later slices may have changed the code they describe. For current behavior read [architecture](../architecture.md), the [ADRs](../adr), [coding style](../coding-style.md) and [CONTEXT.md](../../CONTEXT.md); the [migration ledger](../migration-ledger.md) records the order the slices were built in.

- [specs/](specs) behavior specifications, named by capability slice.
- [reviews/](reviews) the review and verification record of each slice, plus the 2026-10-07 business-flow audits.

Active and unbuilt specifications live in [docs/specs](../specs).
